# 酒管同步：照着做就能用

**记住一句话：换设备前上传，换设备后下载、安排应用、重启服务，再继续聊。**

已经装好？直接看[每天怎么用](#每天怎么用)。首次安装从下面开始。

## 第一次用：先准备好

- 本说明按酒管 **1.17** 编写；电脑还是旧版的，先备份再升级。
- 两端先备份酒管的 `data` 文件夹。首次在**只含测试聊天的独立测试实例**走完整个流程，不要删除现有记录来腾测试环境。
- 两端先导入同一张角色卡，**实际卡文件名也要一致，包括重名后缀**。只看角色显示名相同不够。
- 两端终端分别输入 `git --version`、`node -v`、`npm -v`，都应显示版本号；Node 至少 **20**。提示找不到命令时，先补齐对应工具，再往下做。

目前只同步**一对一聊天记录**，角色卡、世界书、群聊、附件不会一起过去。Termux 真机和真实 GitHub 聊天同步尚未完成验收。

**「上传已保存聊天」会处理当前用户全部已保存的一对一聊天，不只是当前打开的那一段。**

## 第一步：建一个专门存聊天的私有仓库

1. 打开 [GitHub 创建仓库页面](https://github.com/new)。
2. 仓库名填写 `jiuguan-chat-data`，选择 **Private（私有）**。
3. README、`.gitignore`、License 都不要添加，直接创建空仓库。

**你已经建的 `ABGanBei/jiuguan-github-sync` 是公开的插件代码仓库，不能拿它存聊天。**

接着创建一把让插件访问私有仓库的钥匙，也就是令牌：

1. 打开 [细粒度令牌创建页面](https://github.com/settings/personal-access-tokens/new)，填写名称并选择有效期。
2. `Resource owner` 选择存聊天仓库的所有者。
3. `Repository access` 选 **Only select repositories**，只选刚建的 `jiuguan-chat-data`。
4. 在 `Repository permissions` 中把 **Contents** 设为 **Read and write**，其他权限不用加。
5. 生成令牌，妥善保存。稍后要分别填进电脑和手机插件里，**别发给别人，也别截进图片**。

## 第二步：电脑和手机各装一次

每台都要完成下面的 **A 和 B**。A 装操作面板，B 装真正负责同步的后台。

### A. 装操作面板

启动酒管，在「扩展」里的安装入口粘贴这个地址，完成安装：

```text
https://github.com/ABGanBei/jiuguan-github-sync.git
```

### B. 装后台

先关闭酒管的所有页面，再停止酒管服务。

进入你平时启动酒管的文件夹，**确认能看到 `server.js` 和 `package.json`**，然后在这里打开终端。

下面命令只用于**首次安装**，按你的设备选一组，**每行单独执行，任何一行报错就停下来**。

**Windows 电脑：在这个文件夹的资源管理器地址栏输入 `powershell`，回车。**

```powershell
$appDir = (Get-Location).Path
git clone https://github.com/ABGanBei/jiuguan-github-sync.git "$env:USERPROFILE\jiuguan-sync-installer"
node "$env:USERPROFILE\jiuguan-sync-installer\bin\install-plugin.js" --app-dir "$appDir" --enable-server-plugins --install-deps --apply
```

**Android 手机：在 Termux 中先进入上述酒管文件夹，再逐行执行。**

```bash
app_dir="$PWD"
git clone https://github.com/ABGanBei/jiuguan-github-sync.git "$HOME/jiuguan-sync-installer"
node "$HOME/jiuguan-sync-installer/bin/install-plugin.js" --app-dir "$app_dir" --enable-server-plugins --install-deps --apply
```

安装成功后，按你原来的方式启动酒管，再打开一个全新的页面，找到「酒管 GitHub 同步」面板。

> 如果提示目录已存在，别删目录、别反复重装。这些是首次安装命令，不是升级命令。已有源码可使用其安装脚本；已装后台或安装中途失败，先按文末办法排查。

## 第三步：先设置有聊天的那一台

在「酒管 GitHub 同步」面板里填写：

| 位置 | 填什么 |
| --- | --- |
| 仓库 (owner/repo) | `ABGanBei/jiuguan-chat-data`（如果用了别的名字，换成自己的） |
| 分支 | `main` |
| 个人访问令牌 (PAT) | 刚才生成的令牌 |
| 自动检查 | 先保持关闭 |

然后按顺序操作：

1. 点 **「保存」**。令牌框变空是正常的，表示不会把已保存的令牌显示出来。
2. **刚建的空仓库**要勾选 **「连接时初始化空分支」**，再点 **「连接」**。仓库已有同步记录时不用再勾。
3. 等聊天回复生成、保存完成，点 **「上传已保存聊天」**。
4. 确认结果没有报错、没有冲突，再操作另一台。

另一台也填写**同一个私有仓库、同一个分支和有权限的令牌**，点「保存」→「连接」，不用勾初始化。**先按下面的接收流程下载，再继续聊天。连接成功不代表聊天已经下载。**

## 每天怎么用

以「电脑聊完，换手机继续」为例：

**电脑上：**

1. 等回复生成、聊天保存完成。
2. 点 **「上传已保存聊天」**，确认上传成功且没有冲突。

**手机上：**

1. 先别继续聊天，点 **「检查下载」**。
2. 如果提示有暂存的聊天，先关闭访问这台手机酒管的其他页面，再勾选 **「我已关闭其他客户端，并将在重启后重新打开」**。
3. 点 **「安排应用（重启后）」**，确认安排成功。
4. 关闭当前页面，**停止酒管服务，再按原来的方式启动服务**。
5. 打开全新页面，进入对应角色的聊天历史，选择原来的聊天继续。

手机换电脑也完全一样，把两边对调即可。没有新内容时不用安排重启。

**只点下载不会马上更新聊天；只刷新网页也不算重启服务。不要两台同时修改同一段聊天。**

## 卡住了怎么办

| 看到的问题 | 怎么做 |
| --- | --- |
| 提示缺少后台、按钮不可用 | 确认这台设备也做了 B 步，并且重启过服务。 |
| 安装报目录已存在 / `TARGET_EXISTS` | 停止重装，保留目录和报错；不要直接删目录。查看[详细安装说明](installation.md)。 |
| 连接失败 | 核对私有仓库名、网络、令牌是否过期，以及令牌是否只选中了正确仓库并有 Contents 读写权限。首次空仓库要勾初始化。 |
| 出现冲突、删除待处理或其他红色错误 | 先停止同步，保留两边数据和报错，排查后再继续；不要删数据、强行覆盖或反复点击。截图先遮住令牌。 |

私有仓库里的聊天目前**没有额外加密**；删掉当前文件，旧提交里仍可能保留记录。复杂情况请看[详细安装说明](installation.md)。
